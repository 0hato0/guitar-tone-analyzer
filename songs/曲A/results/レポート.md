# 曲A 音作りレポート

作成：2026-10-22　／　解析の数値は summary.md、画像は各フォルダー（delay/・modulation/・check/ など）にあります。
**この音源の前提**：原曲 wav 自体が**モノラル**です（左右の相関 1.00、L−R 成分 0）。ギター分離音源も同じです。そのため、リードとリズムを左右で分けられません。左右の差を使うリバーブやコーラスの手がかりも使えません。数値はすべて「両方のギター＋混ざったキーボードやベース」の合計についてのもので、すべて**推定**です。

## 1. 解析結果の要点

- テンポは約 **105.5 BPM**（曲を通してほぼ一定）。4分＝569ms、付点8分＝427ms、8分＝284ms
- チューニングは A=440Hz より **+6セント**（約441.5Hz）。チューナーの誤差程度
- 歪みは**中くらいのクランチ**の目安。クレストファクターはほとんどのパートで 9〜10dB です。ブレイク（2:47〜2:57）だけ 7.2dB で、低音のパワーコード中心のより歪んだ音です
- 周波数のバランス：リフ（イントロ・間奏・アウトロ）は 800Hz が一番強く、100〜200Hz がかなり少ない（100Hz が -20dB）**細めで中域が前に出た音**です。サビは 400Hz が一番強く、低域もある程度あります
- 空間系は、**数値ではディレイもリバーブも「ある」と言えるだけの根拠が出ませんでした**。理由は、モノラルであること、全帯域が常に鳴っていること、ギターが止まってもキーボードやベースの混ざりが残ることです。「なし」とも断定できません。印象メモの「リフにディレイ？」は尊重し、薄くかける前提で提案します

## 4. 曲中ずっと固定の設定

**ギター**：PRS S2、ブリッジ、ボリューム10、トーン10

**ペダル（接続順）**
| ペダル | オン／オフ | ツマミ（出発点） | 理由 |
|---|---|---|---|
| RAT2 | オフ | — | 歪みは中くらいで十分（クレスト 9〜10dB） |
| OD GLOVE | オフ | — | 同上 |
| BD-2 | **オン** | Gain 9時、Tone 12時、Level 13時 | 低音を締めるブースターとして使う。リフの細い低域と、タッピングの伸びを助ける（一般論からの推測） |
| SCH-Z | オフ | — | コーラスはソロだけなので ZOOM で作る |

BD-2 をオンにすると TONEX への入力が少し強くなります。曲B（スロットA）で BD-2 を使わない場合も、インプットトリムは今のままで構いません（ブースト分は TONEX の Gain を下げて合わせます）。TONEX の入力が赤く光るようなら、トリムの合わせ直しが必要です。

**TONEX（スロットB）**
- **第一候補：12 Always With Me Rhythm（'71 Super Lead・クランチ）**
  - クランチの量が、中くらいの歪み（クレスト 9〜10dB）に合います
  - Marshall の中域の出方が、リフの 800Hz 中心の音に合います
  - スロットAの 6 Always With Me Lead と同じアンプの系統なので、曲間で切り替えても弾き心地と音量が揃えやすいです
- **第二候補：1 Summer Song Lead（'69 Plexi）**
  - 12 よりさらにビンテージ寄りの中域で、リフのソロっぽさを出したいときの候補です。ゲインの量は実機で確認してください
- **その他の候補とEQの違い**（どれも出発点。アンプの性格は一般的な傾向で、プリセットの中身は実機で確認）

  | 候補 | 性格（一般論） | EQの変え方（第一候補との違い） |
  |---|---|---|
  | 20 Time Machine（6100・クランチ） | 低域が締まっていて、Plexi より現代的 | Bass 5（低域はもともと締まっているので削らない）、Middle 4.5／300Hz、Treble 4.5 |
  | 10 The Extremist Rhythm・17 Cool #9（JVM Red Crunch 6L6） | 歪みが多めで締まりがあり、中高域が前に出る | Gain を下げる、Bass 4.5、Middle 5（削らない）、Treble 4〜4.5、Presence 4 |
  | 15 If I Could Fly Clean（Hiwatt クリーン）＋ OD GLOVE オン | 歪みをペダルで作る。粒立ちがはっきりする | Bass 4／120Hz、Middle 5、Treble 5。歪みの量は OD GLOVE の Drive で決める |

- **避けるもの**：5150 系（8・13・16）と Dragon 系（4・5・7・14）のハイゲイン。圧縮が強く、クレスト 9〜10dB の原曲よりつぶれ、コードが濁ります。15 のクリーンは、リフには歪みが足りません
- **外部のモデルとの比較**（本体以外も含めた判断）
  - 音の性格だけなら、本体の 12（または 20）で足ります。原曲の数値（中くらいのクランチ、Marshall 系の中域）から、外部のモデルの方が明らかに近いと言える根拠はありません
  - **決め手はキャビネット**。Satriani のプリセットがキャビネット込みで作られたモデルの場合、グローバルでキャビネットをオフにしても外れない可能性があります。そうなると Marshall のキャビネットと二重になり、こもった箱鳴りになります
  - **確認方法**：TONEX Editor でそのプリセットのモデルが「アンプのみ」か「キャビネット込み」かを見る。または、スタジオでグローバルのキャビネットをオン／オフして音が変わるかを聴く（変わらなければキャビネットが外れていない）
  - **キャビネット込みだった場合の候補**：Factory Presets v2 の「アンプのみ」のバンクにある Plexi 系か 800 系のクランチ（CLAUDE.md にある HG PLEXI・DR 800 など。アンプのみの版があるかは Editor で確認）。ToneNET で探すなら「Plexi crunch amp only」「JCM800 crunch amp only」で、Gain は中くらいのもの
  - 入れる枠：16 Crowd Chant（5150 IIIs Red。ハイゲインで、この曲にも曲Bにも使わない）。入れ替える前に TONEX Editor の Export Library でバックアップし、入れた後でインプットトリム・キャビネットのグローバルオフ・デュアルモードを確認する。Volume はスロットAの曲と同じ音量に合わせ直す
  - EQ の出発点：Plexi 系は①と同じ（Bass 4／120Hz、Middle 4／300Hz）。800 系は低域が締まり中高域と歪みが多いので、Bass 5、Middle 5、Treble 4.5、Presence 4.5、Gain は低め

| Presence | 5 |

## 5. ZOOM のパッチ一覧（バンク2：20〜29）

並び順はどのパッチも「Gt GEQ7 → (Comp) → Chorus → Delay → Room/Hall」です。パラメーター名と数値の範囲は本体の表示を優先してください。ディレイとリバーブは **Tail をオン**にします（踏んだ瞬間に余韻が切れないように）。

**作る順番**：まず基準の **21（サビ）** を作る → 21 を 20・23・24 にコピーして直す → 20 を 22・25 にコピーする。

**音量の方針**：3dB 未満の音量差はピッキングで作ります（ニュアンスを手元で作るため）。パッチレベルを変えるのは、3dB 以上の差があるソロだけです。

| 番号 | パート | エフェクト | Gt GEQ7（100/200/400/800/1.6k/3.2k/6.4k） | パッチレベル |
|---|---|---|---|---|
| 20 | イントロリフ | Delay：Time 285ms・F.B 15・Mix 20／Room（21と同じ） | -8 / -5 / -3 / 0 / 0 / 0 / -2 | 基準と同じ（強めに弾く） |
| **21** | Aメロ1〜サビ1（基準） | Room：Decay 短め・Mix 10（ごく薄く） | -2 / 0 / 0 / 0 / 0 / 0 / -2 | **基準（0dB）** |
| 22 | 間奏リフ〜ソロ前 | 20 のコピー | 20 と同じ | 基準と同じ（強めに弾く） |
| 23 | ソロ（キーボードの代わり） | Chorus：Depth 45・Rate 遅め（15前後）・Mix 50／Delay：Time 427ms（付点8分）・F.B 25・Mix 25／Hall：Decay 中・Mix 20 | -6 / -2 / 0 / 0 / -2 / -4 / -6 | 基準 +3dB |
| 24 | サビ2〜ラスサビ | 21 のコピー | 21 と同じ | 基準（0dB） |
| 25 | アウトロリフ〜最後 | 20 のコピー | 20 と同じ | 基準と同じ（強めに弾く） |

- 20 のディレイの時間は、解析で特定できませんでした。まず 285ms（8分）で原曲と聴き比べて、合わなければ 370ms → 427ms（付点8分）の順で試してください。Mix は「言われれば分かる」程度に小さくします
- 23（ソロ）の高域を削る EQ とコーラスは、ピッキングのアタックとジャリジャリ感を減らして、キーボードのなめらかさに寄せるためのものです（一般論からの推測）。ディレイとホールで、ギターの伸びを残します
- Bメロのタッピング（0:48〜0:55）が埋もれる場合だけ、Bメロ用のパッチ（Comp 入り、基準と同じか +1〜2dB）を足します。ピッキングで音量を上げられない場所なので、例外にします
- 26〜29 は空きです

## 7. 注意点と、確認したいこと

1. **原曲はモノラルでした。** ステレオの原曲（CD音源など）が手に入るなら、入れ替えて再解析すると、左右のギターを分けて判定できる可能性があります
2. **ディレイ（リフ）**：数値では確認できませんでした。聞こえ方は、はっきり繰り返す感じでしたか？　それとも少し伸びる感じでしたか？　繰り返しの間隔が分かれば、遅れ時間を絞れます
3. **タッピング（0:48〜0:55）**：分離音源から抜けているので、何もかかっていない前提でパッチ21にしています。原曲で揺れや残響が聞こえたら教えてください
4. **ソロのキーボード**の音色（シンセのリード、オルガン、エレピなど）が分かれば、コーラスとディレイの値を寄せられます
5. **パート名**（特に「?」のもの）と、1:39.8〜1:48.8 の「間奏2」が何か。sections.csv を直してもらえれば、それで再解析します
6. **チューニング**：最低音は解析ツールの不具合（いつも C2 と出る）で推定できていません。レギュラーチューニング（+6セントは誤差の範囲）の前提です
7. **TONEX の 12 と 1 のゲインの量**とプリセットに入っている内蔵エフェクトは、実機で確認してください。決まったら gear/tonex_slots.md と gear/zoom_banks.md を更新します（あなたが確認してから）
